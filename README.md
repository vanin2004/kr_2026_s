# Платформа для подбора репетиторов и планирования уроков

Проект разрабатывается в рамках курсовой работы. Представляет собой двустороннюю платформу для поиска квалифицированных преподавателей, отслеживания прогресса учеников и управления учебным расписанием. 

## Архитектура и стек технологий
* **Мобильный клиент:** Android-приложение (предназначено для ролей "Ученик" и "Репетитор").
* **Серверная часть:** back-end на Python (API, бизнес-логика, вычисление рекомендаций, хранение расписаний).
* **Авторизация:** Интеграция с сервисом **Keycloak** (SSO, управление пользователями, токенами и разделением ролей).

## Ключевая концепция: Умный алгоритм подбора (Recommendation Engine)
Основа платформы — алгоритм подбора репетиторов, использующий гибридный подход:
1. **Строгая фильтрация (Hard Filters):** Отсев по предмету, бюджету, пересечению свободного времени и минимальному опыту.
2. **Гибкое ранжирование (Soft Scoring):** Вычисление персонального `Match Score` для каждой пары "Ученик-Репетитор" на базе метрик: эффективность (прирост знаний по тестам), качество коммуникации, экспертиза и отзывчивость.
3. **Персонализация (Субъективные веса):** Студент сам задает приоритеты алгоритма в зависимости от целей (фокус на оценки, комфортную коммуникацию или специализацию).

## Основной бизнес-функционал
* **Регистрация и профили:** Управление подробным профилем преподавателя (рабочие слоты, ставки, теги) и профилем ученика (цели обучения, динамика тестов).
* **Календарь и планирование уроков:** Бронирование свободного времени преподавателя, отслеживание статусов занятий, прикрепление ссылок на онлайн-занятия (Zoom, Google Meet).
* **Контроль успеваемости (Тестирование):** Автоматические системные срезы знаний (вводный и ежемесячные контрольные тесты). Прогресс (разница в баллах) напрямую повышает метрику "Эффективности" ($O_1$) преподавателя.
* **Система откликов (Чаты):** Контекстный текстовый мессенджер, который становится доступен только после подачи учеником заявки конкретному преподавателю.
* **Отзывы и метрики:** Модуль автоматического пересчета байесовского рейтинга после проведенных занятий и оценок.
