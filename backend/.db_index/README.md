# Документация проекта (Индекс для ИИ)

Этот каталог содержит структурированную документацию для быстрого понимания архитектуры и кодовой базы проекта. Все ссылки относительные для удобной навигации ИИ.

## Основные разделы

- [Архитектура и инфраструктура](docs/architecture.md) — Обзор микросервисов, Docker, Nginx, Keycloak.
- [Инфраструктурные компоненты](docs/infrastructure.md) — База данных (PostgreSQL), сервер авторизации (Keycloak), Web-сервер (Nginx).

### FastAPI Приложение (`fastapi/`)
- [Ядро приложения (Core)](docs/fastapi/core.md) — Конфигурация (`config.py`) и точка входа (`main.py`).
- [API и Маршрутизация](docs/fastapi/api.md) — Эндпоинты (`api/endpoints.py`) и авторизация (`auth/deps.py`).
- [Бизнес-логика (Services)](docs/fastapi/services.md) — Сервисы для работы с вакансиями (`jobs.py`) и рекомендациями (`suggestions.py`).
- [База данных и Модели](docs/fastapi/db_models.md) — Схемы `Pydantic` и классы для работы с БД (`db/session.py`, `models/schemas.py`).
