# Архитектура и инфраструктура

Проект представляет собой микросервисную архитектуру, развернутую с использованием Docker Compose.

## Структура корня `backend/`

- `docker-compose.yml` — Главный файл оркестрации контейнеров.
- `Makefile` — Скрипты для удобного управления проектом (сборка, запуск, тесты).
- `verify-infrastructure.sh` — Bash скрипт для проверки состояния инфраструктуры.

## Микросервисы

1. **FastAPI (Backend App)**
   - Папка: `fastapi/`
   - Описание: Основной бэкенд на Python.
   - Детали: [Документация FastAPI](../README.md#fastapi-приложение-fastapi).

2. **Nginx (Reverse Proxy)**
   - Папка: `nginx/`
   - Описание: Проксирование запросов, терминация SSL.
   - Файлы: `Dockerfile`, `nginx.conf`, `ssl/`.
   - Детали: [Инфраструктура](infrastructure.md).

3. **Keycloak (Auth)**
   - Папка: `keycloak/`
   - Описание: Управление пользователями и аутентификация/авторизация.
   - Файлы: `realm-export.json`.
   - Детали: [Инфраструктура](infrastructure.md).

4. **PostgreSQL (Database)**
   - Папка: `postgres/`
   - Описание: Основное хранилище данных.
   - Файлы: `init.sql`.
   - Детали: [Инфраструктура](infrastructure.md).
