# Ядро приложения (Core)

**Директория:** `fastapi/src/`

Этот раздел описывает корневые файлы FastAPI приложения.

## Файлы

- **`main.py`**
  - Описание: Точка входа в приложение. Здесь создается экземпляр `FastAPI`, подключаются роутеры из `api/`, настраиваются middleware (CORS и т.д.) и обработчики исключений.
  
- **`config.py`**
  - Описание: Управление конфигурацией с использованием `pydantic-settings`. Чтение переменных окружения (URL базы данных, секретные ключи, настройки Keycloak и т.д.).

## Связанные ресурсы
- Настройки среды лежат в `backend/.env`.
- Логика API: [API и Маршруты](api.md).
