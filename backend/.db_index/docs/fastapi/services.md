# Бизнес-логика (Services)

**Директория:** `fastapi/src/services/`

Этот слой изолирует бизнес-логику от обработки HTTP-запросов (которая находится в `api/`).

## Основные сервисы

- **`services/jobs.py`**
  - Описание: Логика работы с вакансиями (создание, обновление, поиск, фильтрация).

- **`services/suggestions.py`**
  - Описание: Алгоритмы и логика рекомендаций (генерация предложений для пользователей/соискателей на основе вакансий).
  - Связь: Спецификации алгоритма могут быть описаны в корне в файле `suggestion_alg.md`.

## Тестирование
Слой сервисов обильно покрывается юнит-тестами, например `fastapi/tests/test_suggestions_jobs.py`.

## Связанные ресурсы
- Контроллеры, вызывающие эти сервисы: [API и Маршруты](api.md).
- Работа с данными: [База данных](db_models.md).
