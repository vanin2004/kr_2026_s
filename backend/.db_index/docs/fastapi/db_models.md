# База данных и Модели

**Директория:** `fastapi/src/db/` и `fastapi/src/models/`

## Работа с базой данных

- **`db/session.py`**
  - Описание: Настройка подключения к базе данных (обычно SQLAlchemy `sessionmaker`, `create_engine`). Содержит зависимости (Dependency) для получения сессии БД в эндпоинтах (например, `get_db()`).

## Модели и Схемы

- **`models/schemas.py`**
  - Описание: Pydantic модели для валидации входящих данных (Requests) и формирования ответов (Responses).
  - Примечание: Если в проекте используется SQLAlchemy, здесь также могут располагаться ORM модели (либо они лежат отдельно в `models/models.py`).

## Связанные ресурсы
- SQL-инициализация: `postgres/init.sql` (см. [Инфраструктура](../infrastructure.md)).
