# API и Маршрутизация

**Директория:** `fastapi/src/api/` и `fastapi/src/auth/`

## Маршруты (API Routers)

- **`api/endpoints.py`**
  - Описание: Определения HTTP-роутов (GET, POST, PUT, DELETE). Связывает входящие запросы с бизнес-логикой из модуля `services/`.
  - Зависимости: Инжектит сессии БД (`db.session`) и зависимости авторизации (`auth.deps`).

## Авторизация (Auth)

- **`auth/deps.py`**
  - Описание: FastAPI Dependencies (зависимости) для извлечения и валидации токенов (вероятно, JWT, выданных Keycloak). Проверяет права доступа пользователей к эндпоинтам.

## Связанные ресурсы
- Бизнес-логика, вызываемая из эндпоинтов: [Сервисы (Services)](services.md).
- Схемы (Pydantic), используемые для Request/Response: [Схемы и Модели БД](db_models.md).
