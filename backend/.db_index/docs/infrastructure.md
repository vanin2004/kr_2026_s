# Инфраструктурные компоненты

## PostgreSQL
- **Директория**: `postgres/`
- **Ключевой файл**: `postgres/init.sql`
- **Роль**: Инициализация базы данных, создание таблиц и первичных данных при первом запуске контейнера.

## Keycloak
- **Директория**: `keycloak/`
- **Ключевой файл**: `keycloak/realm-export.json`
- **Роль**: Экспортированные настройки realm для Keycloak (роли, клиенты, настройки безопасности). Используется при поднятии сервиса авторизации.

## Nginx
- **Директория**: `nginx/`
- **Ключевые файлы**: 
  - `nginx/nginx.conf` — Конфигурация маршрутизации трафика (например, проксирование `/api` на FastAPI, `/auth` на Keycloak).
  - `nginx/Dockerfile` — Образ для веб-сервера.
  - `nginx/ssl/` — Сертификаты для HTTPS.
